GitHub Pages - JHONY HENAO

1. Extrae este ZIP.
2. Sube TODOS los archivos y la carpeta imagenes al repositorio, no el ZIP dentro del repositorio.
3. Verifica que index.html quede en la raiz del repositorio.
4. En Settings > Pages, selecciona Deploy from a branch, rama main (o master) y carpeta / (root).
5. Guarda y espera a que GitHub Pages publique el sitio.
